# 회장 개인현황판 — Claude Code 인계 문서 (V10 · 2026-11-02)

> **Claude Code에게**: 이 문서는 아이센스그룹 윤석범 회장 개인현황판 구축 작업의 단일 기준 문서다. 착수 전 끝까지 읽고, §8 "결정 필요 사항" 중 미결 항목은 회장님께 먼저 확인한다. 작업 중 결정된 사항은 이 문서 맨 아래 **변경 이력**에 기록하고 버전을 올린다.

---

## 0. 한 줄 요약

오너·CEO 1인용 개인현황판. **지시 관리 + 태그 필터 + 신사업 파이프라인 + AI 사용 모니터링 + 성과 수익가치·레벨 시스템 + 경영학습 문제은행**을 한 사이트에 담는다. 속전속결 원칙: 모듈은 병렬로 만들고, 당일 1차 버전을 띄운 뒤 보강한다.

**현재 상태(V02)**: 클릭 가능한 목업 완성 — 저장소 `my_board`, 루트 `index.html`.

## 1. 원칙

1. **숫자 신뢰도 표기**: 모든 수치에 `측정` / `수기` / `추정` / `미확인` 배지. 추정치는 줄무늬 막대.
2. **가독성 우선**: 상단 핵심 숫자 5개 이내, 본문 최소 15px.
3. **~~회장 전용~~ → 공개용 (V02 변경)**: 개인현황판은 공개용이며 대외비로 하지 않는다. 화이트리스트 로그인은 두지 않는다. 단, **편집(쓰기) 권한**은 회장 계정만 갖도록 할지 실서비스 착수 시 확인한다(§8-6).
4. **비용 표기**: 원화(KRW), 외화는 원화 환산 병기.
5. **불편한 UI는 Claude가 먼저 걸러서 고친다** (V08 회장님 지시). 예: 모든 메뉴에 반복되던 상단 머리말·핵심 숫자는 홈에서만 보이게 함, 내용 없이 늘어난 빈 카드, 탭 이동 후 스크롤 위치 등.
6. **사내 규칙 준수**: 산출물 파일명은 `isens-file-naming`, 브랜드 표기는 "벌툰".

## 2. 기술 스택 (기본안)

| 영역 | 선택 |
|---|---|
| 프론트 | 바닐라 HTML/CSS/JS (JSX 금지) |
| 호스팅 | Vercel (정적 + Serverless Functions, Node) |
| DB·인증 | Supabase (Postgres + Google OAuth + RLS) — 공개 읽기 / 회장 쓰기 정책으로 조정 |
| AI 평가 | Anthropic API (서버 함수, 키는 환경변수) |
| 업무 연동 | Asana API (회장 지시 프로젝트) |
| 코드 저장소 | GitHub `my_board` |

디자인 톤(V07): **벌툰 톤 + 약간의 진중함.** 베이지 바탕·흰 종이 카드·벌툰 골드는 유지하고, 맨 위 머리말을 짙은 에스프레소 띠(금색 가는 테두리)로, 머리말과 각 메뉴 제목을 명조체(Noto Serif KR)로 바꿈. 손그림 배경·기차·이야기책 글꼴은 제거. 오리지널 캐릭터 **"서하 실장"**(40대 비서실장, 패션 일러스트 풍: 낙타색 롱 트렌치, 남색 실크 스카프, 낮게 묶은 흑갈색 머리, 붉은 입술, 금 귀걸이)이 머리말·레벨·경영학습·AI 사용·빈 화면 안내에 등장. 기존 작품 캐릭터는 저작권 때문에 쓰지 않는다.

환경변수: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_KEY`, `ANTHROPIC_API_KEY`, `ASANA_PAT`, `INGEST_TOKEN`. **키는 저장소에 커밋하지 않는다.**

## 3. 화면 구성

```
[상단] 오늘의 브리핑(AI) · 오늘의 한 가지 · 경보 · 오늘 수익가치(천원) · 레벨
[메인] 로고(회장 현황판) 클릭 또는 첫 접속 = 머리말·브리핑·핵심 숫자 + 메뉴별 요약 카드(오늘 할 일·신사업·AI 사용·경영학습)
[메뉴] 오늘 할 일 = 내 할 일·오늘 챙길 지시·결재 대기·일정 (머리말 없음)
[탭]   ① 지시 관리  ② 신사업  ③ 성과·레벨  ④ 경영학습  ⑤ AI 사용  ⑥ 경영 현황  ⑦ 보상 기준
```

### M5 산정 공식 (변경 없음, 목업 구현 확인)

```
V = B × L × F × S × A × N   (천원 단위 반올림)
B = 1인 기준 월 효과 × 유효개월(≤12)   월 효과 = 절감시간 × 30,000원 + 월 매출·이익 기여 + 월 비용절감
L = 1명 1.0 / 2~9 2.0 / 10~29 4.0 / 30~99 6.0 / 100~299 8.0 / 300+ 10.0
F = 문서 1.0 / AI 고도화 1.5 / 코드 1.8 / AI+코드 2.0
S = 1 + 0.5 × max(0, (E−T)/E)   (≤1.5)
A = 에이전트 1.2 / 직접 1.0
N = 1.0 ~ 1.3 (협상, 건당 3회)
```
예시 검증: 360,000 × 8.0 × 2.0 × 1.25 × 1.2 = 8,640,000원 → 8,640천원 (목업 확정 1건으로 탑재)

### M6 경영학습 — 콘텐츠 (V02 변경)

**Claude가 공개 자료를 찾아 추천한다.** 조사 결과는 `docs/question-bank-sources.md`.

- 목업 27문항은 Claude 작성 샘플이며 승인 후 교체한다.

## 8. 결정 사항 (V03 확정)

| # | 항목 | 결정 |
|---|---|---|
| 1 | 지시·신사업 저장 | **Asana 연동.** 등록 시 Asana "회장 지시" 프로젝트에 태스크 생성, 1시간 주기 양방향 동기화 |
| 2 | 수익가치 계수 | **기본값 유지.** 30,000원/시간, 유효개월 상한 12, L 1.0~10.0, F 1.0~2.0. 운영 2주 후 1회 보정 |

### 남은 확인 사항
- ChatGPT·Gemini 관리자(API) 키 보유 여부 (없으면 계속 `미확인`)
- Asana "회장 지시" 프로젝트 ID와 PAT 발급
- 수훈보드 부서 현황판 연동 방법 (M7 부서 신호등)
- 3개 브랜드 핵심 지표의 데이터 원천 (M7)

## 9. 완료 기준

- 로그인 없이 보기 가능, 회장 계정 외에는 등록·수정 차단 확인
- 태그 생성·필터·저장된 보기 동작 — 목업 확인
- 예시 업무로 V 산정 → 협상 → 확정 → 레벨업까지 통과, 천원 단위 — 목업 확인
- AI 사용 스케줄 08~24시 매시, 01~07시 미실행 — 실서비스에서 로그로 확인
- 복습 도전 세트 최근/랜덤 50:50 — 목업 확인(5:5)
- 모든 수치에 배지 표시 — 목업 반영
