# 메뉴(모듈)별 명세 — 하위 세션 작업 기준

공통 규칙
- 바닐라 HTML/CSS/JS(JSX·프레임워크 금지). 목업 데이터만 사용(`js/data.js`의 MOCK). 실제 키·토큰 금지.
- **자기 메뉴 파일만 수정**: `js/views/<메뉴>.js`, `css/views/<메뉴>.css`. 공용 파일(`js/app.js`, `css/style.css`, `js/data.js`, `index.html`)은 꼭 필요할 때만 최소한으로, 바꾼 이유를 보고에 적는다.
- 새 버튼 동작은 `APP.acts['이름']`, 폼은 `APP.forms['이름']`, select 변경은 `APP.changes['이름']`로 등록(메뉴 파일 안에서).
- 샘플 데이터가 더 필요하면 메뉴 파일 안에서 `S.<메뉴>Extra = S.<메뉴>Extra || [...]` 식으로 만든다(data.js 수정 피하기).
- 디자인: 기존 토큰만 사용(베이지 바탕·흰 종이 카드·벌툰 골드, 메뉴 제목 명조). 본문 15px 이상, 모든 수치에 측정/수기/추정/미확인 배지(`badge()`), 휴대폰 폭(400px)에서 가로 스크롤 없음, 다크모드 확인.
- 불편한 UI(빈 공간이 큰 카드, 의미 없는 반복, 누르기 어려운 버튼 등)는 스스로 찾아 고친다.
- 저작권 있는 캐릭터·그림 사용 금지.
- **고를 항목이 많은 칸(사람·직원·부서 등)은 긴 select 대신 입력해서 찾는 칸**으로 만든다(회장님 공통 지시, 2026-11-06 "기본적인 UI/UX는 말 안 해도 해줘"). 이름·부서·직급·초성(예: ㄱㅁㅇ) 검색, ↑↓·Enter로 고르기, Esc로 취소, ×로 지우기, 없는 이름을 치면 원래 값으로 되돌리기. 구현 예: js/views/directives.js 의 picker()·ppOpen()·ppPick() (브랜치 menu/directives).
- 브라우저 confirm()/alert()/prompt()는 공유 화면에서 동작하지 않으니 쓰지 않고 화면 안 2단계 확인을 쓴다.
