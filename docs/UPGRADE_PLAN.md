# 회장 현황판 고도화 기획서 (2026-11-06 밤, 메인 세션 작성)

## 0. 큰 그림 — "회장의 하루 30분 경영 OS"

현황판을 '보는 화면'에서 **'하루를 굴리는 도구'**로 바꾼다.

| 시간 | 회장님이 하는 일 | 주로 쓰는 메뉴 |
|---|---|---|
| 아침 5분 | 오늘 볼 숫자 3개 확인 → 오늘 계획 확정 | 내가 보는 숫자 → 오늘 할 일 |
| 낮 | 지시·결재·이슈 처리 | 지시 관리 · 경영 현황 |
| 틈틈이 | 아이디어 검토, 신사업 판단 | 아이디어뱅크 · 신사업 |
| 저녁 10분 | 오늘 성과 적립·레벨, 복습 5문제 | 성과·레벨 · 경영학습 |
| 주 1회 | 주간 회고 자료 한 장 | 각 메뉴의 주간 리포트 |

**설계 원칙 세 가지**
1. **한 번 누르면 다음 할 일이 보인다**: 모든 화면 맨 위에 "지금 할 일 1개"를 둔다.
2. **메뉴끼리 이어진다**: 한 메뉴의 결과가 다른 메뉴의 입력이 된다(아래 §2 약속).
3. **숫자는 정직하게**: 원천 없는 숫자는 만들지 않는다. 목업 AI 결과에는 반드시 '목업' 표시.

## 1. 공통 규칙 (모든 하위 세션)

- `docs/MODULES.md` 공통 규칙을 그대로 따른다. 특히:
  - 항목 많은 선택칸(사람·부서 등)은 **입력해서 찾는 칸**(이름·부서·직급·초성 검색, ↑↓·Enter, Esc, ×, 없는 값은 원래 값으로). 예: `js/views/directives.js`의 `picker()`.
  - 브라우저 `confirm/alert/prompt` 금지 → 화면 안 2단계 확인.
  - 본문 15px 이상, 측정/수기/추정/미확인 배지, 400px 가로 스크롤 없음, 다크모드.
  - 매출·가맹·로열티 등 사내 실제 수치를 지어내거나 Slack·드라이브에서 가져와 넣지 않는다. 연봉·임금 금지. 저작권 있는 글·그림·캐릭터 금지(문장은 모두 직접 작성).
- **작업 시작 전** 자기 브랜치에 최신 main을 합친다: `git fetch origin main && git merge origin/main` (충돌은 자기 메뉴 쪽 기준으로 정리, 공용 파일은 main 쪽 유지).
- **수정 범위**: 자기 메뉴 파일(`js/views/<메뉴>.js`, `css/views/<메뉴>.css`)만. 공용 파일은 손대지 않는다(필요하면 보고에 '메인에 요청'으로 적는다).
- **단계별로 커밋**: 단계(P1→P2→P3)마다 자기 브랜치에 커밋·푸시. 회장님이 이번 밤샘 작업은 자기 메뉴 브랜치 커밋·푸시를 허락하셨다. **main 합치기·PR·외부 전송(Slack·Asana 실제 발송)·예약 작업 생성은 하지 않는다.**
- **목업 AI**: 실제 AI 호출 대신 규칙 기반 생성으로 만들고 결과에 "목업 AI" 배지를 단다(이미 실데이터 연결이 있는 지시 관리·AI 사용은 기존 방식 유지, 새 기능은 확인 단계 필수).
- 단계마다 Playwright로 1366/400px·라이트/다크 콘솔 오류 0, 가로 스크롤 0, 새 버튼 동작 확인. `./scripts/build-single.sh` 성공 확인.

## 2. 메뉴끼리 잇는 약속 (공용 파일 수정 없이 S에 두는 키)

| 키 | 모양 | 쓰는 법 |
|---|---|---|
| `S.activity` | `[{id, at, menu, type, text, ref}]` | 중요한 행동(완료·확정·채택·결재 등)을 할 때 자기 메뉴가 1줄 추가. 최근 300개만 유지. 메인이 나중에 홈에 '오늘의 활동'으로 묶어 보여 줌. |
| `S.inbox` | `[{id, at, from, to, kind, title, payload, done}]` | 다른 메뉴로 보내기. 각 메뉴는 `to === 자기 메뉴` 인 것을 화면 위 '받은 항목' 상자로 보여 주고, 처리하면 `done: true`. |

보내는 쪽 예: 아이디어뱅크 채택 → `to:'ideas'`(신사업 후보) 또는 `to:'directives'`(지시 초안) / 지시 완료 → `to:'value'`(성과 평가 후보) / 숫자 경보 → `to:'today'`(오늘 할 일 후보) / 경영 현황 결재 지연 → `to:'today'`.
초기화 예: `S.activity = S.activity || []; S.inbox = S.inbox || [];` (각 메뉴 파일에서 각자 해도 안전)

## 3. 메뉴별 고도화 (우선순위 P1 → P2 → P3, 시간이 모자라면 앞 단계까지만)

### 3-1. 오늘 할 일 (`today`) — "하루 작전판"
- **P1** 오늘의 3대 우선순위(Top 3) 고정 칸 · 하루 시간표(일정+할 일을 시간대에 배치, '시간대 지정' 버튼 방식) · 받은 항목 상자(숫자 경보·결재 지연·지시에서 온 것).
- **P2** 아침 계획 마법사(어제 못 끝낸 일·오늘 기한·대기 결재·숫자 경보로 계획 초안 → 수락/수정, 목업 AI) · 저녁 마감 리뷰(끝낸 일·미룬 일·내일 넘길 일 3분 정리, 성과 평가로 보낼 건 `to:'value'`).
- **P3** 집중 모드(한 일만 크게 + 타이머) · 키보드 단축키(N 새 할 일, J/K 이동, X 완료, ? 도움말) · 주간 회고(요일별 완료 수·소요시간).

### 3-2. 내가 보는 숫자 (`numbers`) — "회장 계기판"
- **P1** 숫자 분해 나무(예: 매출 = 점포 수 × 점당 매출) 보기와 목표 역산 · 숫자별 담당자(입력해서 찾는 칸).
- **P2** 이상 신호 감지(3회 연속 하락, 목표 대비 −20%, 갱신 지연) → '오늘 볼 숫자 3개' 자동 선정 + 원인 가설 메모 · 경보를 `to:'today'`로 보내기.
- **P3** 시나리오 계산기("점포 +5, 객단가 +3%면?") · 주간 숫자 리포트(한 장 요약, Markdown 복사).

### 3-3. 지시 관리 (`directives`) — "지시의 일생 관리"
- **P1** 지시 품질 점검기(담당·기한·완료 조건·산출물 형식 누락 경고, 점수) · 지시 서식 모음(자주 쓰는 지시 틀).
- **P2** 담당자별 업무량 지도(사람 × 주) · 병목 감지(보고대기 장기화, 반복 연기) · 독촉 문구 초안(보내기 전 확인 필수, 목업에서는 발송 안 함).
- **P3** 완료 지시를 성과 평가 후보로 보내기(`to:'value'`) · 받은 항목(아이디어뱅크 지시 초안) 처리 · 주간 지시 회고.
- 기존 Asana·Slack 실데이터 연결은 그대로 두고, 새 기능의 실제 외부 전송은 만들지 않는다.

### 3-4. 신사업 (`ideas`) — "사내 벤처 스튜디오"
- **P1** 단계 관문 점검표(검증→PoC→론칭으로 넘어가는 조건) · 가설 보드(고객·문제·해결·수익 가설과 검증 상태) · 실험 기록.
- **P2** 포트폴리오 지도(시장성 × 적합도, 필요 자원 크기로 원 크기) · 진행/중단 결정 기록 · 반대 의견 3개 만들기(목업 AI).
- **P3** 한 장 사업 개요서(린 캔버스 형식) 자동 구성 + Markdown 복사 · 받은 항목(아이디어뱅크 채택분) 처리.

### 3-5. 성과·레벨 (`value`) — "회장 커리어 게임"
- **P1** 업적 배지(첫 에이전트 작업, 주간 10,000천원 돌파 등) · 레벨별 칭호 · 연속 기록 · 받은 항목(오늘 할 일·지시 완료분) 평가 시작.
- **P2** 가치 분석(산출물 형태·영향 인원·에이전트 비중별 가치 차트, "어디에 시간을 쓰면 가치가 큰가" 추천) · 협상 코치(근거가 약한 부분 짚기, 목업 AI).
- **P3** 월간 성과 리포트(확정 Top 5, 레벨 변화) · 레벨업 축하 카드(움직임 줄이기 설정 존중).

### 3-6. 경영학습 (`learn`) — "CEO 아카데미"
- **P1** 간격 반복 복습 일정(맞히면 간격을 늘리는 방식) · 숙련도 지도(과목 × 단원 색상표) · 하루 5분 코스.
- **P2** 사례 문제 모드(일반적인 프랜차이즈 경영 상황을 직접 지어 쓴 사례, 사내 기밀·실제 수치 금지) · 개념 연결 지도.
- **P3** 주간 학습 리포트(XP·정답률 추이) · 오늘의 경영 한 문장 카드(직접 작성, 남의 글 인용 금지).

### 3-7. AI 사용 (`ai`) — "AI 비용·효과 관제탑"
- **P1** 월 예산·한도 설정과 월말 예상 비용 · 이상 사용 경보.
- **P2** AI 효과 배수(성과·레벨의 확정 가치 ÷ AI 비용) · 스킬별 가치 순위.
- **P3** 작업 종류별 알맞은 AI 추천표 · 직원 AI 활용 비교 자리(수훈보드 연동 전이라 미확인으로 자리만).

### 3-8. 경영 현황 (`ops`) — "작전 상황실"
- **P1** 위험 관리표(이슈를 영향 × 가능성 지도로) · 부서 신호등 추이(지난주 대비).
- **P2** 회장 결재 처리 기준(3일 넘으면 경고, 평균 처리일) · 결재 지연을 `to:'today'`로 보내기 · 이슈별 결정 기록(결정·근거·후속 조치).
- **P3** 주간 경영회의 한 장 자료 자동 구성(대기함·위험 부서·이슈 Top 3, Markdown 복사) · 부서별 1:1 점검 질문 만들기.

### 3-9. 아이디어뱅크 + 보상 기준 (`ideabank`, `rules`) — "아이디어 공장"
- **P1** 산출물 평가(별점·채택·보류) · 채택분을 신사업(`to:'ideas'`)이나 지시 관리(`to:'directives'`)로 보내기 · 채택 결과로 주제별 지시문 개선 제안.
- **P2** 산출물 미리보기 고도화(카드뉴스 넘겨 보기, PT 장표형 보기, HTML 리포트 미리보기 — 모두 목업 생성) · 주제끼리 섞어 새 아이디어 만들기.
- **P3** 보상 기준: 과거 확정분 분포 막대와 보정 시뮬레이션 · 협상 사례집(비슷한 사례 찾기).
