# my_board — 회장 개인현황판 (목업)

아이센스그룹 회장 개인현황판의 **클릭 가능한 목업**입니다. 바닐라 HTML/CSS/JS, 빌드 없음.

## 실행
`index.html`을 브라우저로 열면 됩니다. 데이터는 샘플이며 브라우저 localStorage에만 저장됩니다(하단 "샘플 데이터로 되돌리기").

## 구성
| 탭 | 목업에서 되는 것 |
|---|---|
| 상단 | 오늘의 브리핑(일·주·월), 오늘의 한 가지, 핵심 숫자 5개, 측정/수기/추정/미확인 배지 |
| ① 지시 관리 | 목록·칸반·타임라인, 상태 변경, 태그 AND/OR 필터 + 상태·조직·기한, 저장된 보기, 조직별 이행률, 지시 등록, 태그 CRUD·정렬·삭제 확인 |
| ② 신사업 | 단계 칸반, 4축 점수, 다음 액션, 등록 |
| ③ 성과·레벨 | 오늘 할 일 → 시작/종료(측정)·수기 → 완료 입력 → V 산정 → 협상(3회, N≤1.3) → 확정 → 레벨업 |
| ④ 경영학습 | 과목 선택, 풀이 XP+1, 해설, 오답 다시 보기, 복습 도전(최근 50% + 랜덤 50%), 공개 자료 추천표 |
| ⑤ AI 사용 | 토큰·비용(원화 환산), 14일 추이, 기능별 비율, 스킬 Top 10, 수집 경로 점검, 크론 시간표 |
| ⑥ 경영 현황 | 회장 대기함, 부서 신호등, 브랜드 지표(미확인), 이슈·분쟁, 오늘 일정 |
| ⑦ 보상 기준 | 공식·계수표·협상 규칙·변경 이력·협상 로그 |

## 목업에서 대신한 것
- Claude 평가·협상(`/api/evaluate`, `/api/negotiate`) → 규칙 계산
- Asana·Supabase·Google Calendar·수훈보드 연동 → 샘플 데이터
- 문제은행 27문항 → Claude 작성 샘플. 실제 자료는 `docs/question-bank-sources.md`
