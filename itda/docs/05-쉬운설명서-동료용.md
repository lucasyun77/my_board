# 잇다, 5분 만에 이해하기 — 동료용 쉬운 설명서

> 작성 2026-11-14 · 대상: 아이센스그룹 전 직원 (개발을 몰라도 됩니다)
> 읽는 시간: 약 5분

---

## 1분: 한 문장으로

> **잇다는 각자 컴퓨터에서 쓰던 AI 작업 창을 하나의 팀으로 이어 주는 앱입니다.**
> 여러분은 잘하는 일만 하고, 합치는 일은 AI가 합니다.

---

## 2분: 식당 주방으로 비유하면

### 지금 우리 모습 — 각자 집 주방에서 요리하는 요리사들

```
 🏠 디자이너 집 주방     🏠 개발자 집 주방     🏠 마케터 집 주방
   접시 하나 완성          접시 하나 완성         접시 하나 완성
        │                     │                     │
        └──── 누가 들고 뛰어서 한 상에 모아야 함 ────┘
                  (복사·붙여넣기·파일 전달·다시 맞추기)
```

모두 AI라는 좋은 조리 도구를 갖고 있지만, **각자 다른 집 주방**에서 요리합니다. 음식을 한 상에 모으려면 사람이 들고 뛰어야 하고, 간이 서로 안 맞기도 합니다.

### 잇다를 쓰면 — 하나의 식당 주방

```
 ┌──────────────────────── 잇다 식당 ────────────────────────┐
 │                                                          │
 │   [디자인 화구]     [개발 화구]      [마케팅 화구]          │
 │    요리사 김         요리사 이         요리사 박            │
 │        │ "주방장님께 보내 주세요"  │            │           │
 │        └─────────────┬───────────┴────────────┘           │
 │                      ▼                                   │
 │             👨‍🍳 주방장 (팀 메인 세션)                       │
 │             접시를 모아 순서대로 코스로 냄                    │
 │                                                          │
 │   🤵 총지배인 (AI 본부장) — 손에 📖 레시피북(지식위키)       │
 │      · 빠진 메뉴 없나? (계획 대비 검수)                     │
 │      · 쉬고 있는 화구 없나? (멈춘 세션 깨우기)               │
 │      · 오늘 남은 주문은? (당일 후속 계획)                    │
 │      · 손님이 원하는 맛은? (메신저로 직접 물어봄)             │
 └──────────────────────────────────────────────────────────┘
```

| 식당 | 잇다 | 하는 일 |
|---|---|---|
| 요리사 | 나와 내 AI 세션 | 내 전문 분야 요리만 한다 |
| 화구 | 세션 (AI 작업 창 하나) | 한 사람이 화구를 여러 개 켤 수 있다 |
| 주방장 | 팀 메인 세션 | 여러 요리사의 접시를 받아 순서·간을 맞춰 한 코스로 낸다 |
| 총지배인 | AI 본부장 | 레시피북을 들고 전체를 챙긴다 |
| 레시피북 | 지식위키 | 우리 팀의 결정·규칙·브랜드 맛을 적어 둔 책 |
| 주방 게시판 | 연결 지도·대시보드 | 누가 어떤 요리를 몇 번째 다시 했는지 한눈에 |
| 주방 무전기 | 메신저 | 사람끼리, 사람과 총지배인이 대화 |
| 체인점 | 다른 팀·다른 브랜드 | 총지배인 분신이 가서 같은 레시피 핵심을 지키게 함 |

**핵심**: 요리사는 "주방장님께 보내 주세요" 한마디만 하면 됩니다. 들고 뛰지 않아도 됩니다.

## 3분: 나는 무엇을 하면 되나 — 직군별 안내

### 디자이너

| 하던 일 | 잇다에서는 |
|---|---|
| 시안을 파일로 뽑아 개발자에게 메신저로 보냄 | 내 세션에 **"이 시안 팀 메인 세션에 보내서 합쳐 달라고 해"** |
| 개발자가 반영했는지 물어봄 | 연결 지도에서 내 시안의 판 번호와 반영 여부 확인 |
| 브랜드 색·글꼴 규칙을 매번 설명 | 지식위키에 한 번 적어 두면 본부장이 모두에게 지키게 함 |

### 개발자

| 하던 일 | 잇다에서는 |
|---|---|
| 디자인 파일 받아서 직접 옮겨 붙임 | 팀 메인 세션이 받아서 합치기, 나는 결과만 확인 |
| 혼자 디자인까지 대충 함 | 디자인은 디자이너 세션에 맡기고 개발에 집중 |
| 세션 여러 개 켜 두고 잊어버림 | 멈춘 세션은 🔴 표시, 본부장이 다음 일을 챙겨 줌 |

### 마케터

| 하던 일 | 잇다에서는 |
|---|---|
| 상세 페이지 문안을 문서로 써서 전달 | 내 세션에서 문안 작성 → "팀에 보내 줘" |
| 금지 표현을 매번 찾아봄 | 지식위키의 금지 표현 목록을 본부장이 자동으로 대조 |
| 다른 브랜드 팀이 잘한 홍보 방법을 늦게 앎 | 본부장이 다른 팀의 좋은 발견을 바로 알려 줌 |

### 상품기획자

| 하던 일 | 잇다에서는 |
|---|---|
| 컨셉 문서·원료 조사·일정표를 따로 관리 | 프로젝트 하나에 모두 연결, 대시보드에서 진척 확인 |
| 디자인·마케팅·제조 담당에게 일일이 확인 | 본부장이 계획서 대비 빠진 일을 찾아 알려 줌 |
| 브랜드 핵심 속성이 신규 라인에서 흐려짐 | 공통분모 위키로 브랜드 핵심을 모든 팀이 지킴 |

> **공통**: 개발을 몰라도 됩니다. 세션 창을 **쉬운 채팅 방식**으로 바꾸면 말풍선 대화처럼 보입니다.

## 4분: 하루 일과 예시 — 신제품 크림 상세 페이지 만들기

> 아래는 이해를 돕기 위한 **예시** 하루입니다. 시간과 인원은 가상입니다.

```
 시각   누가             무엇을
 ─────  ──────────────  ──────────────────────────────────────────
 09:00  AI 본부장        메신저에 오늘 후속 계획 올림
                         "오늘 할 일 6개. 김디자인 2개, 박마케팅 2개, 이개발 2개"
 09:10  박마케터         내 세션에서 상세 페이지 문안 초안 작성 시작 🟢
 09:30  김디자이너       내 세션에서 첫 화면 시안 작성 시작 🟢
 10:40  박마케터         "문안 팀 메인 세션에 보내 줘"
 10:41  팀 메인 세션     문안 받음 → 지식위키 금지 표현 대조 → 1판 저장
 11:20  김디자이너       "시안 팀 메인 세션에 보내서 문안이랑 합쳐 달라고 해"
 11:22  팀 메인 세션     문안 + 시안 합침 → 2판, 모두에게 알림
 12:00  (점심)
 13:30  AI 본부장        이개발 세션 하나가 40분째 멈춤 🔴 발견
                         → 후속 계획 다음 일("모바일 화면 맞추기")을 보냄 🟢
 14:00  AI 본부장        메신저로 상품기획자에게 질문
                         "성분 강조를 첫 화면에 둘까요, 두 번째에 둘까요?"
 14:05  상품기획자       "첫 화면에" → 본부장이 위키에 결정 기록
 15:30  팀 메인 세션     개발 결과 합침 → 3판
 16:30  AI 본부장        계획서 대비 검수: "제품 사용법 영역 빠짐" 알림
 17:00  김디자이너       사용법 영역 시안 보냄 → 4판
 17:40  AI 본부장        오늘 정리 + 내일 아침 후속 계획 초안 → 메신저 공유
```

**하루 동안 사람이 한 일**: 자기 전문 작업, "보내 줘" 몇 번, 질문 하나에 대답.
**사람이 안 한 일**: 파일 옮기기, 합치기, 누가 멈췄는지 확인하기, 빠진 일 찾기.

## 5분: 자주 하는 오해 5가지

**오해 1. "AI가 내 일을 대신하니까 내 자리가 없어진다."**
아닙니다. 잇다는 **분업**을 되살리는 도구입니다. 디자이너는 디자인을, 마케터는 마케팅을 더 깊게 합니다. 사라지는 것은 파일 옮기기와 합치기 같은 잡무입니다.

**오해 2. "동료가 내 컴퓨터를 마음대로 들여다본다."**
아닙니다. 모든 컴퓨터는 중계 서버로만 연결되고, 내가 보낸 산출물만 전달됩니다. 동료나 본부장이 내 컴퓨터에서 무언가를 실행하려면 내가 미리 허락해야 합니다.

**오해 3. "AI 본부장이 나를 감시하고 평가한다."**
본부장이 보는 것은 **세션(작업 창)이 멈췄는지**, **계획에서 빠진 일이 없는지**입니다. 목적은 일이 끊기지 않게 돕는 것이고, 도움 정도도 내가 끔·가볍게·보통·적극 중에서 고릅니다.

**오해 4. "개발팀 전용 도구라서 나랑은 상관없다."**
아닙니다. 화장품 컨셉, 상세 페이지 문안, 협력사 이메일처럼 결과물을 만드는 모든 일에 씁니다. 쉬운 채팅 방식이면 말로만 요청해도 됩니다.

**오해 5. "메신저가 또 하나 늘어나서 더 바빠진다."**
잇다의 메신저는 프로젝트 안에 붙어 있어서, 대화와 산출물과 결정이 한곳에 모입니다. 본부장이 대화 속 결정을 위키에 정리해 주므로 "그때 뭐라고 했더라" 찾는 시간이 줄어듭니다.

---

## 시작하려면

1. 팀장에게 프로젝트 초대를 받습니다.
2. 내 컴퓨터에 잇다를 설치하고 회사 계정으로 들어갑니다.
3. 세션을 하나 열고, 쉬운 채팅 방식으로 바꿉니다.
4. 평소처럼 AI와 일하다가, 끝나면 **"팀 메인 세션에 보내 줘"** 라고 말합니다.
