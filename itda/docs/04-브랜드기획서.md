## 1. 브랜드 이름 「잇다」의 뜻

「잇다」는 "끊어진 것을 이어 붙이다"라는 우리말 동사다. 제품이 하는 일을 그대로 이름으로 삼았다.

```
          ┌──────── 잇다 ────────┐
          │                      │
   ① 세션을 잇다   ② 사람을 잇다   ③ 팀을 잇다
   AI 작업 창끼리    직군과 직군을     팀과 팀, 브랜드와
   산출물을 주고받게  분업으로 잇게     브랜드를 하나의 오피스로
```

| 층위 | 무엇을 잇나 | 제품에서 실현되는 곳 |
|---|---|---|
| 세션을 잇다 | 서로 다른 컴퓨터·계정의 AI 세션 | 세션 연결, 위계형 합치기 |
| 사람을 잇다 | 디자이너·개발자·마케터·상품기획자 | 메신저, 쉬운 채팅, 연결 지도 |
| 팀을 잇다 | 여러 팀·여러 브랜드·협력사 | AI 본부장 복제, 공통분모 위키 |

**브랜드 자산 표기**

| 항목 | 표기 |
|---|---|
| 한글 이름 | 잇다 |
| 로마자 표기 | ITDA |
| 진행도우미 이름 | AI 본부장 |
| 캐릭터 이름 | 이음이 (8장) |

> 로마자 표기는 해외 상표 등록·도메인 등 브랜드 자산 관리에만 쓰고, 화면과 홍보물에는 한글 「잇다」를 쓴다.

## 2. 브랜드 핵심 가치 3가지

| 가치 | 뜻 | 제품에서의 모습 |
|---|---|---|
| **분업** | 각자 가장 잘하는 일을 한다 | 디자이너는 디자인만, 합치는 일은 팀 메인 세션이 |
| **연결** | 끊긴 곳 없이 흐른다 | 세션·사람·팀이 하나의 지도 위에서 이어짐 |
| **멈추지 않음** | 노는 설비가 없게 한다 | 멈춘 세션 깨우기, 당일 후속 계획 |

## 3. 브랜드 약속 (한 문장)

> **"당신은 가장 잘하는 일만 하세요. 잇는 일은 잇다가 합니다."**

## 4. 브랜드 성격과 말투

잇다는 **"믿음직한 선배 본부장"** 같은 성격이다. 앞에 나서기보다 뒤에서 흐름을 챙기고, 필요한 순간에 짧고 분명하게 말한다.

| 성격 | 이렇게 말한다 | 이렇게 말하지 않는다 |
|---|---|---|
| 차분함 | "디자인 시안 3판이 합쳐졌어요." | "와!! 드디어 합치기 성공!!!" |
| 분명함 | "로그인 화면 검수가 빠졌어요. 지금 맡길까요?" | "혹시 시간 되시면 검토해 보시는 것도…" |
| 존중 | "결정은 팀장님이 해 주세요." | "이렇게 하는 게 정답입니다." |
| 다정함 | "오늘 세션 4개가 쉬지 않고 일했어요. 수고 많으셨어요." | "가동률 목표 미달입니다." (질책 투) |
| 쉬움 | "합치는 중", "멈춤", "판 번호" | 외래어·약어·전문 용어 남발 |

| 번호 | 표어 | 강조점 |

## 6. 시각 정체성

### 6-1. 로고 방향 — "세 점 매듭"

```
        ●
       ╱ ╲
      ╱   ╲          점 세 개 = 세션 · 사람 · 팀
     ●─────●         선 = 잇는 일
                     가운데 겹치는 곳 = 매듭(합쳐진 산출물)
```

- **기본 형태**: 점 세 개가 부드러운 곡선으로 이어져 하나의 **매듭**을 이룬다. 실이 한 번 교차하는 매듭처럼, 선이 서로 지나가며 묶이는 모양.
- **점 색**: 두 점은 짙은 남색, 한 점은 잇다 주황. 주황 점은 "지금 이어지고 있는 곳(AI 본부장)"을 뜻한다.
- **선**: 일정한 두께, 끝이 둥근 선. 딱딱한 직선보다 손으로 묶은 듯한 곡선.
- **글자 로고**: 「잇다」 두 글자. 받침 「ㅅ」의 두 획이 만나는 자리를 매듭의 교차점처럼 다듬는 방향을 검토한다.
- **작은 크기(앱 아이콘)**: 매듭 기호만 쓴다. 바탕은 짙은 남색, 매듭은 연한 베이지, 한 점만 주황.
- **움직임**: 앱 실행·합치기 완료 때 세 점이 차례로 나타나고 선이 이어지며 매듭이 묶이는 짧은 움직임.
- **피할 것**: 사슬·쇠고리처럼 "묶여 갇힌" 느낌, 복잡한 신경망 그림.

### 6-2. 색상 체계

| 역할 | 색 이름 | 16진 색값 | 쓰는 곳 |
|---|---|---|---|
| 주색 | 짙은 남색 | `#1F2A44` | 로고, 제목, 왼쪽 목록 바탕, 앱 아이콘 바탕 |
| 강조색 | 잇다 주황 | `#FF7A45` | 연결선, 주요 단추, AI 본부장 표시, 매듭의 한 점 |
| 보조색 | 연한 베이지 | `#F6F1E7` | 넓은 바탕, 카드 바탕, 위키 화면 |
| 상태색 | 초록 | `#2BB673` | 일하는 중, 합치기 완료, 검수 통과 |
| 상태색 | 경고 빨강 | `#E5484D` | 멈춘 세션, 충돌, 검수 실패 |

**색 비율 원칙 (화면 기준)**

```
 연한 베이지  ██████████████████████████████  약 60%  바탕
 짙은 남색    ███████████████                  약 30%  글자·틀
 잇다 주황    ████                             약 8%   강조
 초록·빨강    █                                약 2%   상태 표시만
```

- 주황은 "이어짐"을 뜻하는 색이므로 아무 곳에나 쓰지 않는다.
- 초록과 빨강은 **상태 표시 전용**이다. 꾸밈에 쓰지 않는다.
- 어두운 화면 방식에서는 바탕을 짙은 남색으로, 글자를 연한 베이지로 뒤집는다.

## 8. 캐릭터 — AI 본부장을 상징하는 「이음이」

> 기존 작품의 캐릭터를 쓰지 않은 **잇다만의 창작 캐릭터 설정**이다. 실제 그림은 디자인팀 시안 후 상표 검색으로 비슷한 캐릭터가 없는지 확인한다.

```
        ╭───╮
       ( ◕ ◕ )      ← 둥근 실타래 모양 머리
        ╰─┬─╯
     ~~~~~┼~~~~~    ← 주황 실 한 가닥이 목도리처럼
         ╱ ╲
       [위키수첩]     ← 늘 들고 다니는 작은 수첩
```

| 항목 | 설정 |
|---|---|
| 이름 | 이음이 |
| 정체 | 끊어진 실을 이어 주는 **실타래 요정**. 팀의 모든 실(세션)이 어디로 이어지는지 아는 유일한 존재 |
| 생김새 | 연한 베이지 실을 둥글게 감은 몸통, 짙은 남색 눈, 목에 두른 주황 실 한 가닥. 실 끝이 작은 매듭으로 묶여 있다 |
| 소지품 | 「위키수첩」— 팀의 결정·규칙·레시피를 적어 둔 수첩. 새 팀원에게 먼저 펼쳐 보여 준다 |
| 성격 | 차분하고 꼼꼼하다. 앞에 나서지 않지만 빠진 일은 반드시 짚는다. 칭찬을 아끼지 않는다 |
| 버릇 | 멈춘 세션을 발견하면 주황 실을 살짝 당겨 "다음 할 일 여기 있어요" 하고 깨운다 |
| 능력 | 자기 실을 조금 풀어 **분신**을 만들어 다른 팀에 보낸다(본부장 복제). 분신들은 같은 실로 이어져 있어 좋은 소식을 곧바로 나눈다 |
| 하지 않는 일 | 사람 대신 결정하지 않는다. 남의 실을 허락 없이 당기지 않는다(권한 원칙) |
| 표정 4종 | 기본(미소) · 생각 중(수첩을 봄) · 알림(실을 당김) · 축하(매듭이 반짝임) |
| 쓰는 곳 | 본부장 코칭 띠, 빈 화면 안내, 합치기 완료 알림, 사내 교육 자료 |

## 9. 출시 홍보 단계 계획

```
 1단계 사내 시범            2단계 협력사              3단계 공개
 ─────────────────▶ ─────────────────▶ ─────────────────▶
 아이센스그룹 안            함께 일하는 협력사          일반 회사
 브랜드 팀 몇 곳            디자인·제조·유통 협력사     소규모 회사 중심
```

| 단계 | 목표 | 핵심 메시지 | 홍보 방법 | 확인할 것 |
|---|---|---|---|---|
| 1. 사내 시범 | 실제 업무에서 "보내 줘 → 합치기"가 통하는지 검증 | 잘하는 일만 하세요. 잇는 일은 잇다가 | 사내 설명회, 쉬운 설명서 배포, 이음이 안내 화면, 시범 팀 사례 공유 | 세션 가동률, 합치기 대기 시간, 직원 반응 |
| 2. 협력사 | 회사 밖 팀과도 이어지는지 검증 | 우리 회사와 협력사가 하나의 팀처럼 | 협력사 초청 시연, 공동 프로젝트 하나로 시작 | 회사 밖 공유 통제, 보안 요구 사항 |
| 3. 공개 | 소규모 회사로 확산 | 따로 일하고, 함께 끝낸다 / 작은 회사에 큰 회사의 연결을 | 출시 발표, 사례집(사내·협력사 사례), 체험 요금제 | 가입·유지 비율, 요금제 반응 |

> 각 단계의 시작 시점은 「06-투자유치자료」 실행 계획과 맞추며, 2단계 이후 일정은 1단계 결과를 보고 회장님이 확정한다.

## 10. 경쟁 제품과 위치

### 10-1. 비교 표

| 비교 항목 | 협업 메신저류 | 업무관리 도구류 | AI 코딩 도구류 | **잇다** |
|---|---|---|---|---|
| 무엇을 잇나 | 사람과 사람 | 할 일과 담당자 | 한 사람과 AI | **AI 세션과 AI 세션** |
| 여러 사람의 AI 결과물 합치기 | 사람이 직접 | 사람이 직접 | 한 사람 범위 | **팀 메인 세션이 자동으로** |
| 진행 감독 | 없음 | 사람이 상태를 갱신 | 없음 | **본부장이 멈춤·누락 감지** |
| 지식 쌓기 | 대화가 흩어짐 | 문서 따로 관리 | 세션마다 따로 | **지식위키 자동 정리** |
| 팀 간 노하우 전파 | 사람이 전달 | 사람이 전달 | 없음 | **본부장 복제·공통분모 위키** |
| 비개발 직군 사용 | 쉬움 | 쉬움 | 어려움 | **쉬운 채팅 방식으로 쉬움** |

### 10-2. 위치 지도

```
                    팀 전체를 다룬다
                          ▲
       업무관리 도구류      │        ★ 잇다
       협업 메신저류        │
                          │
 사람이 일한다 ◀───────────┼───────────▶ AI가 일한다
                          │
                          │        AI 코딩 도구류
                          │
                          ▼
                    한 사람을 돕는다
```

**위치 한 줄**: 잇다는 기존 도구를 **대체하기보다 그 사이를 잇는** 자리에 선다. 팀 전체를 다루면서, 실제 일은 AI 세션이 하고, 사람은 결정과 전문 작업에 집중한다.
