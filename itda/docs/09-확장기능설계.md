# 아이센스투게더 확장 기능(모드) 설계서

> 작성 2026-11-21 · 마더 세션 · 회장님 지시: "새 프로젝트 위에 이 앱에 기능을 추가하는 세션을 두자(탭 추가, 채널 위치 변경, 클로드처럼 모드 기능)"
> 이 문서는 하위 세션들이 똑같이 따르는 **약속**이다. 이름과 모양을 바꾸려면 마더 세션과 먼저 정한다.

## 1. 한 줄 요약

사이드 맨 위 **「앱 고치기」 세션**에 평소 말로 부탁하면, 클로드 코드가 **배치 설정**이나 **확장** 파일을 만들고 앱이 즉시 다시 불러 바뀐다. 확장은 **격리된 작은 창(샌드박스 아이프레임)** 안에서만 돌고, 정해진 통로로만 앱과 말한다.

## 2. 두 종류

| 종류 | 파일 | 할 수 있는 것 |
|---|---|---|
| 배치 설정 | `layout.json` | 채널 목록 위치(왼쪽·오른쪽), 탭 순서·숨기기, 강조색, 글자 크기, 사이드 폭 |
| 확장 | `<확장아이디>/manifest.json` + HTML 파일 | 아티팩트 공간에 새 탭, 세션 창 위 띠, 확장 전용 저장소, 허락된 동작 보내기 |

## 3. 폴더 (데스크톱 앱)

```
문서/iSensTogether/앱고치기/            ← 「앱 고치기」 클로드 세션의 작업 폴더
  CLAUDE.md                              ← 확장 만드는 법 안내서(앱이 넣어 줌, 클로드가 읽음)
  layout.json                            ← 배치 설정
  extensions/
    today-tab/
      manifest.json
      tab.html
      .history/manifest-<시각>.json      ← 되돌리기용 이전 판(앱이 보관)
```

## 4. 배치 설정 `layout.json`

```json
{
  "channelListSide": "left",          // "left" | "right"  메신저 채널 목록 위치
  "tabOrder": ["map","board","chat","wiki","agent"],   // 확장 탭 아이디도 넣을 수 있음 "ext:today-tab:main"
  "hiddenTabs": [],
  "accent": "#FF7A45",                // 강조색(16진)
  "fontScale": 1.0,                   // 0.85 ~ 1.3
  "sideWidth": 260                    // 200 ~ 360
}
```
모르는 칸은 무시하고, 범위를 벗어난 값은 가장 가까운 허용값으로 맞춘다.

## 5. 확장 `manifest.json`

```json
{
  "id": "today-tab",                  // 영문 소문자·숫자·하이픈, 3~40자
  "name": "오늘 할 일",
  "version": "1.0.0",
  "description": "오늘 계획 중 내 일을 모아 보여 줍니다",
  "permissions": ["read:plan", "read:sessions", "op:plan"],
  "tabs":  [{ "id": "main", "title": "오늘 할 일", "file": "tab.html" }],
  "bands": [{ "id": "cost", "file": "band.html", "height": 36 }]
}
```
- `tabs`: 아티팩트 공간에 탭 추가. 탭 아이디는 `ext:<확장아이디>:<탭아이디>`
- `bands`: 세션 창 맨 위 띠(높이 24~120)
- `permissions`(허락 목록): 켜기 전에 사람에게 보여 주고 허락을 받는다.
  - 읽기: `read:project` `read:sessions` `read:plan` `read:artifacts` `read:messages` `read:wiki` `read:members`(이메일 제외)
  - 동작: `op:post` `op:plan` `op:wiki` `op:board`
  - 그 밖의 동작(세션 실행, 차단, 산출물 지우기 등)은 확장에 주지 않는다.

## 6. 확장 창과 앱 사이 약속 (postMessage)

확장 HTML은 `<iframe sandbox="allow-scripts" srcdoc=…>` 안에서 돈다(같은 출처 아님, 외부 접속은 콘텐츠 보안 정책으로 막음). 확장 안에서는 앱이 넣어 주는 작은 도우미 `itda` 를 쓴다.

```js
// 확장 HTML 안에서
itda.ready(ctx => { /* ctx: { extId, target: "tab:main"|"band:cost", theme: {accent, dark} } */ })
itda.onState(state => { /* 허락받은 자료만: { project, sessions, plan, artifacts, messages, wiki, members, me } */ })
await itda.op({ op: "plan", projectId, title: "할 일" })   // 허락받은 동작만, 결과 { ok, error? }
await itda.store.get("key"); await itda.store.set("key", value)   // 확장 전용 저장소(내 컴퓨터)
itda.toast("저장했습니다")
itda.resize(80)                                            // 띠 높이 바꾸기
```

실제 주고받는 메시지:
| 방향 | type | 내용 |
|---|---|---|
| 앱→확장 | `init` | `{ extId, target, theme }` |
| 앱→확장 | `state` | 허락받은 자료(현재 프로젝트 기준), 바뀔 때마다(초당 최대 2번) |
| 확장→앱 | `op` | `{ reqId, op }` → 앱이 `{ type:"opResult", reqId, ok, error? }` |
| 확장→앱 | `store.get` / `store.set` | `{ reqId, key, value? }` → `{ type:"storeResult", reqId, value }` |
| 확장→앱 | `toast` | `{ text }` |
| 확장→앱 | `resize` | `{ height }` (띠만) |

## 7. 관리와 공유

- **확장 관리 화면**(설정 안 「확장」): 목록, 켜기·끄기, 허락 목록 보기, 이전 판으로 되돌리기, 지우기, 팀에 공유.
- **처음 켤 때**: 허락 목록을 보여 주고 「켜기」를 눌러야 동작. 새 판이 허락을 더 달라고 하면 다시 묻는다.
- **팀 공유**(중계 서버):
  - 동작 `shareExtension { ext: { id, name, version, description, permissions, tabs, bands, files: { "tab.html": "…" } } }` → 서버 상태 `extensions[]` 에 `status: "대기"` 로 올라간다.
  - 관리자가 `approveExtension { id }` 하면 `status: "승인"` 이 된다. 팀원은 확장 관리 화면에서 「팀 확장」을 골라 켤 수 있다(각자 허락).
  - `removeExtension { id }` 는 관리자 또는 올린 사람만 할 수 있다.
  - 확장 파일 하나는 200KB 이하, 확장 하나는 1MB 이하.

## 8. 「앱 고치기」 세션

- 사이드 맨 위, 「새 프로젝트」 단추 위에 고정한다. 아이콘 🛠, 이름 「앱 고치기」. 사람마다 하나이고, 중계 서버에 올리지 않는 내 컴퓨터 전용 세션이다.
- 데스크톱 앱에서는 작업 폴더 `문서/iSensTogether/앱고치기` 로 진짜 클로드 세션을 켠다(`claude_start` 의 cwd). 처음 켤 때 앱이 `CLAUDE.md`(안내서)를 넣어 둔다.
- 클로드가 한 차례 끝낼 때마다(result 사건) 앱이 폴더를 다시 읽는다. 바뀐 배치 설정은 바로 적용하고, 새 확장이나 새 판은 **허락 카드**로 보여 주고 사람이 켜게 한다.
- 시연 방식(브라우저·미리보기): 「오늘 할 일 탭 만들어 줘」 같은 말에 미리 준비한 견본 확장을 흉내로 만들어 보여 준다. 「채널 목록 오른쪽으로」 같은 말에는 배치 설정을 바꾼다. 모두 「(시연)」을 붙인다.

## 9. 안전 원칙

1. 확장은 격리된 창 밖의 화면을 직접 건드리지 못한다.
2. 외부 서버로 자료를 보낼 수 없다(콘텐츠 보안 정책: `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:`).
3. 허락 목록 밖의 자료·동작은 앱이 거절한다.
4. 회원 이메일, 차단 목록, 감사 기록은 확장에 주지 않는다.
5. 사내 지침: 확장을 회사 밖에 공개 배포하려면 전략실 승인번호가 필요하다(앱 안 팀 공유는 해당 없음).
