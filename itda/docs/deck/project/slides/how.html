문을 열지 않음

내 컴퓨터로 들어오는 문 없이, 계속 열린 통로(웹소켓)로 바로 전달합니다. 팀장 컴퓨터에서 버튼 하나로 서버가 됩니다.

주인 허락 우선

남의 세션에는 “요청”만 갑니다. 본부장 권한은 읽기만 / 제안만 / 실행까지 중에서 주인이 정합니다.

지금의 한계

시제품은 연결 동작 확인 단계입니다. 암호화·계정 인증·조직 관리는 사내 시범 단계에서 갖춥니다.

잇다 · 투자 설명 자료
보안 질문이 반드시 나옵니다. “밖으로만 연결”과 “주인 허락 우선”을 먼저 말하고, 시제품의 한계(암호화·인증 미완)는 숨기지 않고 다음 단계 일정과 함께 답합니다.
